# Prompt 實驗室（Prompt Lab）

可重複使用的 Prompt 作品集網站。每一頁收錄一個實際設計、測試過的 prompt，包含使用情境、可複製的原文、輸出範例與設計理由。

- 課程：TAICA 生成式 AI：文字與圖像生成的原理與實務 — 第九週作業
- 技術：純 HTML / CSS / JavaScript，使用 GitHub Pages 發布
- 專案規則：見 [AGENTS.md](./AGENTS.md)（CLAUDE.md 指向同一份規則）

## 收錄清單

| 編號 | 標題 | 分類 | 對應課程 |
|---|---|---|---|
| P001 | 職場霸凌語言偵測 Bot | 分析判斷 | Week 3 |
| P002 | 公告海報插圖生成 | 圖像生成 | 延伸練習 |
| P003 | 行政公告白話改寫助手 | 文字生成 | 延伸練習 |

## 如何新增一個 Prompt

對 AI 說：「請依照 AGENTS.md 新增一頁，主題是＿＿＿，prompt 原文如下……」
AI 會依第 7 節流程完成：複製範本 → 填寫 6 個區塊 → 更新首頁卡片與數量 → 更新本表。
